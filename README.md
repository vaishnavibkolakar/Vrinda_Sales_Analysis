# Vrinda Store Sales Analysis Dashboard

## Project Overview
Analyzed Vrinda Store sales data using Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard Design

## Key Insights
- Identified top-performing states
- Analyzed sales by gender and age group
- Compared orders and revenue trends
- Studied sales channels and order status
